# Full-Stack Restaurant Site for Burger Heaven — Project Specification

## Project Summary
A full-featured restaurant website for Burger Heaven in New Westminster, BC. Built with a retro diner aesthetic, it includes menu browsing, daily rotating specials, a photo gallery, promotional pages, and a job application system with resume uploads — all backed by secure form handling and email integration.

---

## Roles
- Full-Stack Developer
- Frontend Developer

---

## Technologies
- Next.js 14
- TypeScript
- Tailwind CSS
- Resend API
- Google Maps API

---

## System Overview

### Design & UX
- Retro diner aesthetic with fully responsive layout
- Daily rotating menu items
- Photo gallery
- Mile High Challenge promotional page

### Forms & Communication
- Contact form with server-side email delivery via Resend API
- Job application system supporting resume file uploads
- Comprehensive input validation and HTML escaping for all user-generated content

### Integrations
- Google Maps embedded location display
- Email notifications via Resend

---

## Outcome
A production-ready restaurant website delivering an engaging retro diner experience with a full online presence, customer contact functionality, and a job application pipeline.
